# Artud Midas

Artud Midas is a technology platform for nightlife business growth. It helps venues and operators build stronger customer relationships, understand performance, and grow sustainably.

## Focus Areas

- **Customer Loyalty** — Tools to reward, retain, and re-engage guests
- **Analytics** — Insights into traffic, spend, and campaign performance
- **Community** — Features that connect venues with their audience and each other
- **Business Intelligence** — Data-driven decisions for operations, marketing, and growth

## Project Structure

```
artud-midas/
├── assets/     # Shared media, icons, and brand resources
├── backend/    # API, services, and server-side logic
├── database/   # Schemas, migrations, and data models
├── design/     # UI/UX specs, wireframes, and design system
├── docs/       # Project documentation and guides
└── frontend/   # Progressive Web App (PWA) client
```
